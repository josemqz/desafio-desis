# Desis backend

## Funciones importantes de Makefile

- `make db`: crea la base de datos.
- `make migrate`: aplica migraciones de base de datos.
- `make serve`: inicia el servidor de desarrollo.
- `make setup`: prepara el despliegue, creando la bd y ejecutando migraciones.

**Entidades**:  
Product -> producto  
Warehouse -> bodega  
Branch -> sucursal  
Currency -> moneda
